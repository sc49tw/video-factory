# LLFC style guide

The authoritative ideation rules are in `creative-direction.md`. Read that file
before proposing or revising any concept.

Production implementation:

- Use clear A2 English with short, independent sentences suitable for TTS.
- Preserve the professional illusion; narration never signals a joke.
- Keep report typography, paper texture, institutional branding, margins,
  stamps, projector treatment, and slide hierarchy consistent.
- Preserve approved narration and character appearance.
- Image prompts describe visible composition and action without requesting
  captions, subtitles, logos, or embedded text.
