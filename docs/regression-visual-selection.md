# Visual Selection Regressions

Compact record of rejected visual candidates whose broad description matched
but whose visible content introduced an unintended narrative. Each entry is a
regression case for the **Semantic Action Check** (Playbook §9.1): a
permanent veto applied during autonomous visual candidate selection, after the
avoid-list check and before technical/motion QA.

Add an entry here when a new episode produces a candidate that would have been
accepted on broad match alone. Keep each entry to: intended beat, broad match,
actual action, unintended narrative introduced, and the accepted replacement.

---

## ESSY-0005 N015-S2 — empty wallet

- **Episode / slot:** ESSY-0005, N015-S2
- **Rule:** Semantic Action Check (Playbook §9.1)
- **Rejected asset:** Pexels 16940174 ("a man sitting on a couch with a dog",
  Cameron Gawn) — the cut shows a man looking into an empty wallet.
- **Intended beat:** *nothing to prove.* The narration offers permission to stop
  performing; the visual job is a person simply present, with no task, result,
  problem, or audience on display.
- **Broad match:** an elderly man alone in a room with no work or audience.
- **Actual action:** he looks into an empty wallet.
- **Unintended narrative introduced:** financial scarcity / retirement hardship —
  a causal story the narration never mentions and that contradicts the beat.
- **Accepted replacement:** Pexels 7113136 ("elderly man with glasses sitting in
  an armchair in a warmly lit room") — the person is simply present without a
  task, result, problem, or additional causal story.
- **Lesson:** a prop as small and "incidental" as a wallet can anchor a whole
  causal reading. Check for held objects and readable props, not just subject
  and composition.
